# Слайс 1 (Inbox): скриншоты настоящего окна

Снято `scripts/screenshot-window.sh` (`screencapture -x -o -l <id окна>`, только окно Kinige) со **собранного** приложения (`scripts/build-app.sh`, ad-hoc подпись), macOS 26.5.2, Apple M3 Pro, окно 1280 × 800. Ввод и щелчки — через автоматизацию macOS (System Events, вставка из буфера обмена, настоящие Enter, Shift+Enter, Tab). Данные — чистые каталоги (`KINIGE_DATA_DIR`, `KINIGE_MIRROR_DIR`); русский интерфейс — запуск с `-AppleLanguages "(ru)"`, английский — язык системы (`en-KZ`).

Порядок Tab в настоящем окне (AX-атрибут `AXFocusedUIElement` после каждого нажатия): чат в сайдбаре → кнопка профиля → лента → кнопки действий каждой записи (одна остановка на запись) и ссылки → поле ввода; в окне настроек — «Закрыть» → «Выбрать…» → «Обычный» (группа размера текста — одна остановка) → по кругу; Esc возвращает фокус на кнопку профиля. На этой машине `AppleKeyboardUIMode = 0` (полный доступ с клавиатуры выключен), Tab работает: `wry` ставит `WKPreferences.tabFocusesLinks` (macOS 12+).

Рядом: `tests.txt` (вывод проверок), `cold-start.txt` (холодный старт, цель < 1,5 с), `kill9.txt`, `mirror-files.txt`.

Не снято: состояние «папка не выбрана» в настоящем окне (при папке по умолчанию `~/Documents/Kinige` оно возможно, только если ОС не отдала каталог «Документы»; оно есть в историях Storybook), запрос macOS на доступ к «Документам» (при запуске из терминала не появился; при запуске из Finder не проверялся).
