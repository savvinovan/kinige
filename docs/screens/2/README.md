# Слайс 2 (быстрый захват): скриншоты настоящих окон

Снято `scripts/screenshot-window.sh` (`screencapture -x -o -l <id окна>`: только окно Kinige — главное, окно захвата, меню значка; рабочего стола и других программ на снимках нет) со **собранного** приложения (`scripts/build-app.sh`, ad-hoc подпись), macOS 26.5.2, Apple M3 Pro. Данные — чистые каталоги (`KINIGE_DATA_DIR`, `KINIGE_MIRROR_DIR`); русский интерфейс — запуск с `-AppleLanguages "(ru)"`, английский — `"(en)"`. Хоткеи, ввод и щелчки — настоящие события macOS (System Events, `CGEventPost`), ввод только когда пользователь не за машиной (по `HIDIdleTime`) и когда активна ожидаемая программа. Окно захвата открывали ⌥Space при активном **Finder**: во всех прогонах `front=Finder` до и после (журнал — `live-run.txt`, окно захвата не активирует приложение).

**Вид окна захвата изменён по приёмке (22.10.2026): скруглённая плавающая панель вместо прямоугольного окна 560 × 360.** Снимки `01`–`06`, `14`, `30`, `31` показывают прежний вид (они подтверждают сценарии, а не внешний вид); актуальный вид — `40`–`46` ниже.

## Не снято и ограничения

- **Состояние «занято другой программой» в живом окне получить не удалось.** `RegisterEventHotKey` (через него работает `global-hotkey` на macOS) не отказывает из-за сочетаний других программ и системных: из отдельного процесса успешно регистрируются даже ⌘Space, ⌘Tab, ⌃Space (проверено, 12 сочетаний). Отказ приходит только при невозможной записи. Состояние «не назначено: занято» есть в данных (`ShortcutStatus.state = taken`), в истории Storybook (`storybook-shortcut-taken-ru.png`) и проверено тестами `hotkeys` и IPC на поддельном реестре; обнаружение занятости на macOS — открытый вопрос (`CopySymbolicHotKeys` нашёл бы только системные сочетания, чужие программы — никак).
- Мигание значка при успешном хоткее буфера: в журнале есть метка `flash` (`KINIGE_TRACE=1`), но сам кадр мигания снять нельзя — значок в menu bar не окно приложения; снят только покой (`08-tray-icon-ru.png`).
- Окно захвата над полноэкранной программой и на другом рабочем столе не проверялось (флаги панели `canJoinAllSpaces`, `fullScreenAuxiliary` выставлены).
- Вставка ⌘V в окне захвата не проверялась (панель не активирует приложение; ⌘V обрабатывает WKWebView).

- **Раунд исправлений:** `10-settings-shortcuts-ru.png` переснят (подпись «Сохранить буфер во «Входящие»», умолчание ⌃⌥N); остальные снимки сделаны со старым умолчанием ⌥Space (на них оно видно только в настройках, `12`–`13`). Живая проверка раунда выполнена (22.10.2026 около 14:50 МСК, на свободных ⌃⌥⇧K / ⌃⌥⇧J во временной базе): сбой буфера без падения (`30`), курсор в конце черновика (`31`), серия показов над Finder и Telegram — потерь ключевого статуса 0 из 24, цикл `rekey` удалён; журнал — конец `live-run.txt`.
