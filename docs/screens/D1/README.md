## Открытые вопросы к слайсу 1

- **Tab в WebKit пропускает кнопки.** В WKWebView на macOS по умолчанию Tab переходит только между полями ввода и ссылками, а кнопки пропускает (системная настройка «Полный контроль клавиатуры» и поведение Safari/WebKit). В D1 это не чинилось: все кнопки — настоящие `<button>` с видимым кольцом `:focus-visible`, в Chromium (Storybook, тесты) Tab ходит по ним. В слайсе 1 нужно проверить обход клавиатурой в настоящем окне Tauri и решить, нужен ли явный `tabindex`/обработчик или достаточно документировать настройку macOS.
- **Открытие ссылок.** Щелчок и Enter по ссылке в записи в D1 отменяются (`Message`), в системном браузере ссылки не открываются. Слайс 1: команда или плагин Tauri для открытия внешнего адреса и capability (§12.3), с отрицательным тестом на чужие схемы.
- **Подсказка «Появится позже»** у кнопок поля ввода (`aria-disabled`) убирается по слайсам: эмодзи — 3, файл — 7, голосовое — 7a.
