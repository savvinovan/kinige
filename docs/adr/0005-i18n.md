# ADR-0005: Многоязычный интерфейс — i18next + react-i18next

Дата: 2026-10-21. Статус: **принято** (слайс 1). ТЗ §2.1, §15: все строки в файлах переводов с первого слайса, английский первым, русский вторым.

## Контекст
Слайс 1 переносит строки интерфейса (включая строки D1) в файлы переводов. Нужны: склонение по правилам языка (в русском one / few / many / other), типизированные ключи, синхронная инициализация (окно не должно мигать пустыми строками), без шага компиляции переводов (Vite 8, Storybook 10, Vitest 5 не трогаем).

## Решение
**`i18next` 26.5.4 + `react-i18next` 17.1.0** (версии проверены на npm 21.10.2026).
- Совместимость: `react-i18next` 17.1.0 — peer `react >= 16.8.0` (у нас 19.3.1), `i18next >= 26.2.0`, `typescript ^5 || ^6 || ^7` (у нас 6.0.3). `i18next` 26.5.4 — peer `typescript ^5 || ^6 || ^7`.
- Склонение — встроенное, через `Intl.PluralRules` (ключи `<имя>_one`, `_few`, `_many`, `_other`; CLDR), без ICU-парсера в рантайме.
- Ключи типизированы по `web/src/locales/en.json` (`CustomTypeOptions.resources`): нет ключа — ошибка `tsc`. Тест проверяет, что набор ключей `ru.json` совпадает с `en.json`.
- Переводы лежат в бандле (`resources`, `initAsync: false`): инициализация синхронная. Экземпляр создаётся через `createInstance`, без глобального состояния: тесты и истории Storybook берут свой язык.
- Язык выбирает Rust по предпочитаемым языкам системы (`sys-locale`, первый язык списка: `ru` — русский, любой другой — английский); `navigator.language` в WKWebView не используется (не проверено, что он следует системе). Даты и числа — `Intl` на этом языке.
- Цена: бандл вырос примерно на 50 КБ (минифицированный, ~16 КБ gzip) по пробной сборке `esbuild` «React + i18next + react-i18next» против «React» (274 020 против 223 487 байт; gzip 85 594 против 69 260).

## Отклонено
- **Lingui** — макросы и шаг компиляции каталогов: лишний этап сборки в Vite 8 / Storybook 10 / Vitest 5.
- **react-intl** — ICU-парсер в рантайме, ключи без типов; запасной вариант, если i18next не подойдёт (подтвердилось, что подходит).
- **Paraglide** — свой компилятор и формат сообщений.

## Последствия
Новая строка интерфейса сначала появляется в `en.json` и `ru.json`; кириллица в `web/src` вне `locales`, демо-данных, историй и тестов запрещена тестом. Переключатель языка, перевод системного меню macOS и границы дня — не в слайсе 1.
