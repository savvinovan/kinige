# ADR-0005: Multilingual UI — i18next + react-i18next

Date: 2026-10-21. Status: **accepted** (slice 1). PRD §2.1, §15: all strings in translation files from the first slice, English first, Russian second.

## Context
Slice 1 moves the UI strings (including the D1 strings) into translation files. What is needed: plural forms by the rules of the language (one / few / many / other in Russian), typed keys, synchronous initialization (the window must not flash empty strings), no translation compilation step (Vite 8, Storybook 10, Vitest 5 are not touched).

## Decision
**`i18next` 26.5.4 + `react-i18next` 17.1.0** (versions checked on npm on 21.10.2026).
- Compatibility: `react-i18next` 17.1.0 — peer `react >= 16.8.0` (we have 19.3.1), `i18next >= 26.2.0`, `typescript ^5 || ^6 || ^7` (we have 6.0.3). `i18next` 26.5.4 — peer `typescript ^5 || ^6 || ^7`.
- Plural forms are built in, via `Intl.PluralRules` (keys `<name>_one`, `_few`, `_many`, `_other`; CLDR), without an ICU parser at runtime.
- Keys are typed from `web/src/locales/en.json` (`CustomTypeOptions.resources`): a missing key is a `tsc` error. A test checks that the key set of `ru.json` matches `en.json`.
- Translations are in the bundle (`resources`, `initAsync: false`): initialization is synchronous. The instance is created via `createInstance`, without global state: tests and Storybook stories take their own language.
- The language is chosen by Rust from the system's preferred languages (`sys-locale`, the first language of the list: `ru` — Russian, anything else — English); `navigator.language` in WKWebView is not used (it is not verified that it follows the system). Dates and numbers — `Intl` in this language.
- Cost: the bundle grew by about 50 KB (minified, ~16 KB gzip) according to a trial `esbuild` build of "React + i18next + react-i18next" versus "React" (274,020 versus 223,487 bytes; gzip 85,594 versus 69,260).

## Rejected
- **Lingui** — macros and a catalog compilation step: an extra build stage in Vite 8 / Storybook 10 / Vitest 5.
- **react-intl** — an ICU parser at runtime, untyped keys; a fallback if i18next did not work out (it was confirmed that it does).
- **Paraglide** — its own compiler and message format.

## Consequences
A new UI string first appears in `en.json` and `ru.json`; Cyrillic in `web/src` outside `locales`, demo data, stories and tests is forbidden by a test. A language switcher, translation of the macOS system menu and day boundaries are not in slice 1.
