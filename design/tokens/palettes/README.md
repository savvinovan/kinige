# Палитры-кандидаты D1

Шесть тёмных палитр на одних и тех же ролях (`PALETTE_ROLES` в `web/src/ui/tokenSource.ts`): `umber`, `moss`, `dusk` (авторские, §11.2) и три по мотивам готовых схем: `nord`, `catppuccin-mocha`, `catppuccin-macchiato`. Какая действует по умолчанию, задаёт `../active.json`. Все проходят тест контраста (`web/src/ui/tokens.test.ts`; вывод — `docs/screens/D1/tokens-contrast.txt`).

## Откуда взяты официальные цвета

Значения не по памяти, а из первоисточников (скачаны 20.10.2026); копия лежит в `design/sources/official-palettes.json`.

| Схема | Источник | Версия |
|---|---|---|
| Nord | репозиторий `nordtheme/nord`, файл `src/nord.css` (переменные `--nord0` … `--nord15`); те же 16 значений на https://www.nordtheme.com/docs/colors-and-palettes | коммит `1cef71605416a222e57225b544540ce0fcec18d4` (ветка `develop`, пакет 0.2.1). Самый свежий тег в репозитории — `v0.2.0` (2016), он старее. Лицензия по `package.json`: MIT |
| Catppuccin Mocha и Macchiato | репозиторий `catppuccin/palette`, файл `palette.json`, ключи `mocha` и `macchiato` | тег `v1.8.0`, коммит `07d02aa110ef9eb7e7427afca5c73ba9cf7f8ebd`, поле `version` = 1.8.0. Лицензия: MIT |
| Роли цветов Catppuccin | официальный style guide `catppuccin/catppuccin`, `docs/style-guide.md` | `main` на 20.10.2026 (коммит `d09787dd98ca6fba08af5ef2ae94a7e09f17daca`) |

Тест `web/src/ui/palettes.provenance.test.ts` следит за честностью разметки: у каждой роли этих палитр указано происхождение (`$extensions.kinige.origin` в токене, видно в Storybook «Основа / Цвета»); цвет, названный официальным, обязан совпасть с источником по значению и по имени; цвет, названный подгонкой, не должен совпадать ни с одним официальным.

Обозначения в таблицах: **офиц.** — официальный цвет в той роли, которую рекомендует схема; **офиц., другая роль** — официальный цвет, но схема рекомендует его для другого; **подгонка** — нашего цвета в схеме нет, он выведен по формуле.

## Насколько палитры отходят от §11.2

§11.2 требует «тёплый тёмный фон», «приглушённый акцент» и не допускает тёмно-фиолетового стиля макетов. Тон (hue) и насыщенность считаются в HSL.

| Палитра | Фон / бумага, тон ° / насыщенность | Что отходит от §11.2 |
|---|---|---|
| umber, moss, dusk | 20–75° / 4–12 % | Ничего: тёплый или нейтрально-тёплый графит |
| nord | 220° / 16–17 % | Фон холодный синий, не тёплый. Акцент бирюзово-голубой приглушённый, фиолетового нет. Отступление среднее: холодно, но не «фиолетово» |
| catppuccin-macchiato | 232–233° / 23 % | Фон холодный сине-серый, насыщеннее Nord. Текст и акцент с синей насыщенностью 68–83 % (не приглушённые, как в §11.2). Отступление заметное |
| catppuccin-mocha | 240° / 21 % | Фон на 240° — это уже сине-фиолетовый, самый близкий к «тёмно-фиолетовому стилю», который ТЗ исключает; акцент синий насыщенностью 92 %. Отступление наибольшее |

Если пользователь выберет холодную палитру, отступление от §11.2 («тёплый тёмный фон») фиксируется в ADR D1; ТЗ не правится без отдельного решения.
