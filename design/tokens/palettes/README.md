# Палитра D1: graphite (нейтральный графит)

Палитра одна: `graphite` (тёмная, серые поверхности без цветового оттенка, акцент голубой). Выбрана пользователем 20.10.2026 (ADR-0004) по тёмным темам ChatGPT и Claude. Остальные кандидаты удалены вместе с тестами и историями: авторские `umber`, `moss`, `dusk`, `catppuccin-mocha` и `catppuccin-macchiato`, а также сине-графитовый Nord, который был палитрой D1 до этого решения (файл `nord.json` переименован в `graphite.json`, поверхности заменены). Роли описаны в `PALETTE_ROLES` (`web/src/ui/tokenSource.ts`), контраст проверяет `web/src/ui/tokens.test.ts` (вывод — `docs/screens/D1/tokens-contrast.txt`). Какая палитра действует по умолчанию, задаёт `../active.json`.

## Откуда что взято

- **Поверхности, текст и разделитель — авторские.** Нейтральный серый, насыщенность 0 (все три канала цвета равны; тест проверяет). Ориентир — тёмные темы ChatGPT (около `#212121`) и Claude; поверхности ещё темнее, как просил пользователь («темнее и белее»).
- **Акцент и кольцо фокуса — официальный `nord8` `#88c0d0`**, как и раньше.
- **Ошибка — подогнанный `nord11`** (`#bf616a`, красный Aurora), светлота 56,5 % → 73,5 %: `#d89fa4`.

Официальные значения Nord для проверки лежат в `design/sources/official-palettes.json` (только `nord8` и `nord11`; источник — репозиторий `nordtheme/nord`, файл `src/nord.css`, коммит `1cef71605416a222e57225b544540ce0fcec18d4`, ветка `develop`, пакет 0.2.1; те же значения на https://www.nordtheme.com/docs/colors-and-palettes, сверено 20.10.2026; лицензия по `package.json`: MIT).

Тест `web/src/ui/palettes.provenance.test.ts` следит за честностью разметки (`$extensions.kinige.origin` у каждой роли, видно в Storybook «Основа / Цвета»):

- «авторский» — цвет нейтральный серый и не совпадает ни с одним цветом Nord (его нельзя выдать за официальный);
- официальное имя Nord (`nord8 …`) — цвет обязан совпасть с источником по значению и по имени;
- «подгонка» — цвет не должен совпадать ни с одним официальным.

## Что изменено по живому окну (20.10.2026)

1. Первая редакция: официальный Nord, плашка `#3b4252`. Пользователю: «фон слишком яркий, шрифт серый».
2. Вторая: те же сине-графитовые тона (220°), но темнее, текст почти белый.
3. Третья (эта): **нейтральный графит**, без синевы. Оттенок поверхностей ушёл, остался голубой акцент.

Иерархия (проверяет тест): фон окна темнее бумаги ленты, плашка светлее бумаги, блок кода темнее плашки, подсвеченная плашка светлее обычной, поле в фокусе светлее поля.

## Насколько палитра отходит от §11.2 (ТЗ v0.7)

Нейтральный серый без оттенка; акцент голубой приглушённый; фиолетового и тёплых тонов нет. Принцип «тёплая тёмная бумага» отменён в v0.7 (ADR-0004).
