# Шрифты (D1)

Набор «serif + sans + mono»: `literata` (Literata + Inter + JetBrains Mono). Выбран пользователем 20.10.2026; кандидаты `source` (Source Serif 4 / Sans 3 / Code Pro) и `plex` (IBM Plex) удалены вместе с файлами, токенами и переключателем в Storybook. Лицензия у всех трёх семейств — SIL Open Font License 1.1, текст лежит в `OFL.txt` рядом с файлами каждого семейства.

## Откуда взяты

Все файлы — из репозитория Google Fonts, коммит `47d54ca1ebb14fd864695f1d39dc734f39017c33` (ветка `main`, 2026-10-16), папка `ofl/<семейство>/`: `https://raw.githubusercontent.com/google/fonts/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/<семейство>/<файл>.ttf`. Там же брались `OFL.txt`, `METADATA.pb` и `upstream_info.md` (из них — первоисточники ниже).

Скачанные TTF лежали в отдельной папке, ничего из них не запускалось. Единственное преобразование — упаковка TTF в WOFF2 библиотекой fontTools 4.67.0 (brotli 1.2.0): `TTFont(src)`, `font.flavor = "woff2"`, `font.save(dst)`. Подмножества (subsetting) не делались, файлы переименованы (убраны скобки и запятые из имён). Помимо упаковки, fontTools при сохранении изменил два служебных места: удалил таблицу `DSIG` (цифровая подпись; после любого пересохранения она всё равно недействительна) и переписал дату изменения `head.modified`. Контуры глифов (координаты, флаги, концы контуров), оси переменных шрифтов и таблица `name` совпали с исходными (сверено fontTools: 0 отличающихся глифов). Сверка делалась на всех 15 файлах-кандидатах, включая 4 оставшихся в репозитории.

## Что проверено по файлам

Проверка — тест `web/src/ui/fonts.test.ts` (читает сами woff2: таблицы `cmap`, `OS/2`, `fvar`, `name`) и независимо fontTools 4.67.0 (результаты совпали). Для каждого файла: есть весь русский алфавит `А–я`, `Ё`, `ё`; не меньше 90 кодовых точек в блоке U+0400–U+04FF; в строке лицензии внутри файла — «Open Font License»; курсив и вес в файле совпадают с заявленными в токене.

Набор описан в `design/tokens/fontsets/literata.json`: семейства (с запасными системными) и начертания (`fontFace`: семейство, стиль, вес или диапазон, файл). Все три шрифта переменные: одна ось веса покрывает regular / semibold / bold.

| Роль | Файл | Вес в файле | Кириллица (кодовых точек в U+0400–U+04FF) |
|---|---|---|---|
| serif, прямой | `literata/Literata-Variable.woff2` | ось wght 200–900, ось opsz 7–72 | 118 |
| serif, курсив | `literata/Literata-Italic-Variable.woff2` | ось wght 200–900, opsz 7–72 | 118 |
| sans | `inter/Inter-Variable.woff2` | ось wght 100–900, opsz 14–32 | 248 |

Нет: курсива sans и mono (не используется). Все нужные regular / italic / semibold / bold есть; курсив serif любого веса 200–900 тоже (в том числе жирный курсив). Без Reserved Font Name.

## Исключение: системный эмодзи-шрифт

Эмодзи чатов в сайдбаре рисует системный эмодзи-шрифт (`font.family.emoji`: Apple Color Emoji, Segoe UI Emoji, Noto Color Emoji). Это единственное исключение из правила «шрифты только встроенные»: эмодзи — данные пользователя (`chats.icon`), цветные эмодзи не встраиваем (файлы большие, лицензии разные), а вид эмодзи на каждой ОС свой по определению. Тест `fonts.test.ts` проверяет, что у роли `emoji` нет встроенных начертаний и что других ролей без файлов нет. Текст интерфейса и записей системных шрифтов не использует.

## Что не входит и не проверено

- Не взяты начертания, которых нет в ролях D1: Thin–Light, ExtraBold–Black, курсив sans/mono.
- Рендер шрифтов проверялся в Chromium (Storybook, Linux-контейнер). WKWebView (настоящее окно Tauri) на этих файлах не проверялся; переменные шрифты WKWebView поддерживает, но это ещё предстоит увидеть глазами. Windows и Linux — слайс 10.
- Размер: три папки вместе около 1,2 МБ в woff2.
