# Шрифты (D1)

Набор «sans + mono»: `inter` (Inter для текста записей и интерфейса + JetBrains Mono для кода). Выбран пользователем 20.10.2026 по живому окну (ADR-0004): сначала была Literata для текста записей, но на 14 px засечки шумят, поэтому она удалена вместе с файлами, токенами `font.family.serif` и записями в тестах; раньше удалены кандидаты `source` (Source Serif 4 / Sans 3 / Code Pro) и `plex` (IBM Plex). Лицензия у обоих семейств — SIL Open Font License 1.1, текст лежит в `OFL.txt` рядом с файлами каждого семейства.

## Откуда взяты

Все файлы — из репозитория Google Fonts, коммит `47d54ca1ebb14fd864695f1d39dc734f39017c33` (ветка `main`, 2026-10-16), папка `ofl/<семейство>/`: `https://raw.githubusercontent.com/google/fonts/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/<семейство>/<файл>.ttf`. Там же брались `OFL.txt` и `METADATA.pb` (из них — первоисточники ниже).

Скачанные TTF лежали в отдельной папке, ничего из них не запускалось. Единственное преобразование — упаковка TTF в WOFF2 библиотекой fontTools 4.67.0 (brotli 1.2.0): `TTFont(src)`, `font.flavor = "woff2"`, `font.save(dst)`. Подмножества (subsetting) не делались, файлы переименованы (убраны скобки и запятые из имён). Помимо упаковки, fontTools при сохранении удаляет таблицу `DSIG` (цифровая подпись; после любого пересохранения она всё равно недействительна) и переписывает дату изменения `head.modified`. Контуры глифов, оси переменных шрифтов и таблица `name` при упаковке не менялись (для первых двух файлов сверено fontTools: 0 отличающихся глифов; курсив Inter добавлен 20.10.2026 тем же способом, глифы сверены только тестом и снимками).

| Папка | Семейство | Первоисточник (из METADATA.pb), коммит | Автор | TTF в Google Fonts, sha256 (первые 16 знаков) |
|---|---|---|---|---|
| `inter/` | Inter | github.com/rsms/inter, `66647c0b` (Inter 4.1) | Rasmus Andersson | `29160a80ff49ddca` (прямой), `acd98e64795781b2` (курсив) |
| `jetbrains-mono/` | JetBrains Mono | github.com/JetBrains/JetBrainsMono, `19371302` | JetBrains | `48715a42ec242c21` |

`OFL.txt` Inter из Google Fonts совпадает с файлом в репозитории (проверено `diff`).

## Что проверено по файлам

Проверка — тест `web/src/ui/fonts.test.ts` (читает сами woff2: таблицы `cmap`, `OS/2`, `fvar`, `name`) и независимо fontTools 4.67.0 (результаты совпали). Для каждого файла: есть весь русский алфавит `А–я`, `Ё`, `ё`; не меньше 90 кодовых точек в блоке U+0400–U+04FF; в строке лицензии внутри файла — «Open Font License»; курсив и вес в файле совпадают с заявленными в токене. Тест требует от набора: sans regular, italic, semibold, bold и bold italic; mono regular и bold.

Набор описан в `design/tokens/fontsets/inter.json`: семейства (с запасными системными) и начертания (`fontFace`: семейство, стиль, вес или диапазон, файл). Все файлы переменные: одна ось веса покрывает regular / semibold / bold.

| Роль | Файл | Вес в файле | Кириллица (кодовых точек в U+0400–U+04FF) |
|---|---|---|---|
| sans, прямой | `inter/Inter-Variable.woff2` | ось wght 100–900, opsz 14–32 | 248 |
| sans, курсив | `inter/Inter-Italic-Variable.woff2` | ось wght 100–900, opsz 14–32 (`OS/2` помечен курсивом) | 248 |
| mono | `jetbrains-mono/JetBrainsMono-Variable.woff2` | ось wght 100–800 | 98 |

Нет: курсива mono (не используется). Все нужные regular / italic / semibold / bold есть, включая жирный курсив Inter. Без Reserved Font Name.

## Исключение: системный эмодзи-шрифт

Эмодзи чатов в сайдбаре рисует системный эмодзи-шрифт (`font.family.emoji`: Apple Color Emoji, Segoe UI Emoji, Noto Color Emoji). Это единственное исключение из правила «шрифты только встроенные»: эмодзи — данные пользователя (`chats.icon`), цветные эмодзи не встраиваем (файлы большие, лицензии разные), а вид эмодзи на каждой ОС свой по определению. Тест `fonts.test.ts` проверяет, что у роли `emoji` нет встроенных начертаний и что других ролей без файлов нет. Текст интерфейса и записей системных шрифтов не использует.
